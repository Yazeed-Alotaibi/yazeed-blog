    What the desk does

    Seven things you can do here besides read a number.
    Capabilities
    • 01 Added 2026-09-01

      Export to Excel

      Every calculator downloads as a real .xlsx: the parameters you entered, each result with its verdict sentence, the formula, and its chart as a native, editable Excel chart wherever one belongs.

      Excel button on every card
    • 02 Added 2026-09-04

      Project register

      Name a project and the desk keeps its readings apart from the next one’s — in this browser, and nowhere else. Export a project as a sync file to carry it to another machine.

    • 03 Added 2026-09-04

      Import readings

      Paste or upload a CSV or JSON file, check every row in a preview, then merge it into the current project or replace it. Nothing is applied until you choose.

    • 04 Added 2026-09-03

      Charts you can read

      Every plot answers the arrow keys, hover and touch with the value under the pointer, and a View data table sits beneath it for screen readers and spreadsheets.

      Under every chart
    • 05 Added 2026-09-02

      Full analysis pages

      Some calculators deserve more than a card. The earned value page works the method through end to end, with the calculator running beside the prose.

      Read the earned value analysis
    • 06 Added 2026-09-01

      Share a reading

      Copy link puts the figures you entered into the address, so a colleague opens the same reading. The desk also remembers your last visit and offers those readings back.

      Copy link on every card
    • 07 Added 2026-09-04

      Review lens

      Switch between cost, schedule, and forecast to trace the readings that belong in the same management conversation. The highlighted path stays connected while the live inputs change.

      Cost · schedule · forecast

    Nothing matches that. Try a metric (CPI, EAC), a technique (PERT, float), or a domain (risk, quality).
